Extension Overview (확장 프로그램 화면 구성)

VS Code Sidebar 영역에서 백엔드 연결 상태, 현재 워크스페이스, Git 정보, 프로젝트 목록, 의존성 그래프 상태를 한곳에서 확인하고 제어하는 초기 대시보드입니다.

🟢 서버 상태 확인

백엔드 /health 응답 결과(연결 상태, endpoint, latency)를 표시하며, 모델 목록 조회와 sLLM 답변 스트리밍 설정(ON/OFF)을 관리합니다. endpoint를 클릭해 주소를 변경하거나 새로고침 버튼으로 즉시 재연결할 수 있습니다.

📂 현재 프로젝트 정보

현재 열린 워크스페이스 이름, Git 원격 저장소, 현재 커밋의 짧은 SHA, 브랜치 정보를 표시합니다. 의존성 그래프 분석 상태와 진행률을 확인하고 그래프 열기와 프로젝트 브리핑을 실행할 수 있습니다. 서버 DB에 없는 로컬 프로젝트에는 인덱싱 필요 상태가 표시됩니다.

🔄 프로젝트 목록

Local 프로젝트와 서버 DB에 인덱싱된 프로젝트 목록(GET /projects?view=repos)을 함께 제공합니다. 프로젝트를 펼쳐 커밋을 선택하면 RAG 질의에 사용할 프로젝트와 커밋이 바뀌며, 인덱싱 필요(⚡) 및 업데이트 필요(⚠️) 상태도 확인할 수 있습니다.

📖 도구 및 Guide

Vision Guidebook 패널을 토글하고, VS Code 전역 저장소에 있는 채팅 이력 DB(Chat history.db) 위치를 운영체제 파일 탐색기에서 열 수 있습니다.

FILE DEPENDENCY (파일 의존성 탐색기)

현재 활성화된 파일의 의존성 관계(Imported Files 및 Referenced By Current File)를 트리 형태로 직관적으로 파악할 수 있는 화면입니다.

📂 FILE DEPENDENCY 트리 구조 및 기능 설명

현재 파일에서 가져온 외부 모듈/파일 목록과, 반대로 현재 파일을 참조하고 있는 연관 파일들을 한눈에 파악하여 효율적인 연관 코드 수정을 지원합니다.

  • Imported Files: 현재 파일에서 import하여 사용 중인 모듈 및 소스 파일 목록을 표시합니다.
  • Referenced By Current File: 현재 파일 또는 모듈을 참조하고 있는 프로젝트 내 타 파일 목록을 표시합니다.

코드 빠른 질문 (Code Quick Ask)

코드 작성 및 유지보수 중 빠르게 질문을 던질 수 있는 기능 구성입니다.

🖱️ 자동 코드 인젝션

코드를 드래그하고 우클릭 메뉴에서 "vision: 이 코드 설명해줘"를 선택하면, 선택된 파일명과 코드 블록(@vision)이 VS Code 챗 창에 자동으로 첨부됩니다.

⚡ 실시간 AI 설명

전송 시 백엔드와 연동되어 해당 코드에 대한 상세한 AI 설명을 즉시 받아볼 수 있습니다.

의존성 그래프 시각화 (Dependency Graph)

프로젝트 내부 파일 간의 호출 및 참조 관계를 시각적으로 분석하고 상태를 관리하는 기능입니다.

📈 인터랙티브 그래프 맵

프로젝트 파일의 import 관계를 분석하여 `.vscode/dependency-graph.json`에 저장하며, Git HEAD 변경 시 변경 파일 중심으로 갱신됩니다.

  • 분석 상태 표시: 분석 대기 중, 구조 분석 중 [Node/Edge], 분석 완료, 최신 상태, 분석 실패 상태를 단계별로 안내
  • 웹뷰 연동: 분석 완료 후 활성화되는 **Vision - 의존성 그래프** 버튼을 통해 별도의 웹뷰 패널 오픈

프로젝트 브리핑 (Preview brief.md)

현재 워크스페이스의 브리핑을 열거나 생성하여 코드베이스 이해를 돕습니다.

📄 프로젝트 개요 및 요약 (Document Summary)

brief.md 파일이 존재하면 마크다운 미리보기를 열고, 없으면 백엔드 `/briefing?project_id=...`에서 받아 워크스페이스에 저장한 뒤 미리보기를 제공합니다. 생성된 문서는 프로젝트 정체성, README 등 주요 문서 요약, 진입점과 기능 목록을 한 번에 확인하는 온보딩 자료입니다.

  • 프로젝트 정의: 프로젝트의 핵심 역할, 대상 환경 및 목적 요약
  • 문서 요약: README, 개발 문서, 변경 로그 등 주요 문서의 역할과 온보딩 정보 제공
  • 기능 목록: Chat, 스트리밍, 파일 의존성, 그래프, Git 갱신, 이력 저장 등 확인된 기능 정리

🚀 진입점(Entry Points) 및 함수 분석

선택된 프로젝트 ID를 기반으로 brief-{projectId}.md를 생성하거나 기존 파일을 Markdown 미리보기로 연동합니다. 생성 결과에 코드 근거가 부족한 항목은 확인 필요로 구분해야 합니다.

  • 진입점 관리: 분석된 핵심 파일 위치와 진입점 판정 근거 명시
  • 함수 리스트: 분석 가능한 진입점의 함수 목록과 구조 요약
  • 분석 한계: 근거를 찾지 못한 기능이나 사용자 대상은 추정하지 않고 확인 필요로 표시

Vision Chat 상세 가이드

VS Code Chat API 기반의 Vision Assistant 참가자 동작, 명령어 및 설정 안내입니다.

🤖 Vision Assistant 개요

VS Code 내장 Chat UI에서 @vision 참가자를 선택하여 프로젝트 기반 질문을 진행합니다.

  • 등록 ID: vision.chat
  • 참가자 이름: @vision (Vision Assistant)

⚡ 핵심 채팅 처리 프로세스

사용자 질문 입력 시 컨텍스트와 대화 이력을 결합하여 SSE 스트리밍 응답을 출력합니다.

  • 프롬프트 구성: 질문 정리 및 대화 이력(context.history) 병합
  • 컨텍스트 포함: 현재 활성 편집기 파일 전체 텍스트 자동 첨부
  • 응답 전송: 백엔드 SSE 기반의 점진적 스트리밍 응답 제공 (chatHandler_SSE.ts)

🛠️ 챗 참가자 명령어 (Chat Commands)

채팅창에서 @vision 뒤에 입력하여 RAG(검색 증강 생성) 동작 방식을 제어할 수 있는 전용 명령어입니다.

  • /no-rag: "RAG 기능을 사용하지 않습니다." - 일반 LLM 단독 모드로 답변을 생성합니다.
  • /ragonly: "RAG 기능만 사용해서 그래프에 출력합니다." - RAG 검색 결과만을 활용하여 분석 내용을 구성합니다.

💡 주요 명령어 및 활용 팁

채팅 창과 편집기 명령어를 통해 손쉽게 AI 컨텍스트를 활용할 수 있습니다.

  • 코드 설명: 우클릭 메뉴 또는 명령 팔레트 vision: 이 코드 설명해줘 (ID: vision.explainFile)
  • 가이드북 조율: vision.showGuide / vision.toggleGuide
  • 컨텍스트 팁: 활성 편집기를 유지한 채 질문하면 해당 코드 컨텍스트가 함께 전송됩니다.

⚙️ 설정값 및 기능 연결 매핑

확장에서 관리하는 주요 전역 설정값들의 역할입니다.

  • vision.endpoint: 백엔드 AI 서버 주소
  • vision.modelId: 현재 사용 모델 ID
  • vision.projectId / vision.commitId: RAG 질의 및 선택 프로젝트/커밋 식별자
  • vision.streaming: Chat 답변 스트리밍 활성화 여부 (기본값: true)
  • vision.showGuideBook: 활성화 시 가이드북 자동 실행 여부 (기본값: false)

상세 기능 명세서

현재 구현된 Vision의 화면, 명령, 백엔드 연동 및 데이터 저장 동작을 기능 단위로 정리합니다.

구분 기능명 상세 설명 참고 사항
Sidebar 서버 상태 및 설정 /health 연결 상태, endpoint, latency, 모델 목록을 표시하고 endpoint와 답변 스트리밍 설정을 변경합니다. vision.endpoint, vision.modelId, vision.streaming
Sidebar 현재 프로젝트 및 Git 정보 워크스페이스, 원격 저장소, 현재 커밋, 브랜치 정보를 표시하고 프로젝트 정보와 Git 정보를 새로 조회합니다. Git 저장소가 없으면 Git 정보가 없다고 표시
Sidebar 프로젝트 목록 및 커밋 선택 Local 프로젝트와 GET /projects?view=repos 결과를 함께 표시합니다. 프로젝트를 펼쳐 커밋을 선택하면 RAG에 사용할 projectId와 commitId를 저장합니다. ⚡ 인덱싱 필요, ⚠️ DB 업데이트 필요
Sidebar 프로젝트 브리핑 기존 brief.md 또는 brief-{projectId}.md를 Markdown 미리보기로 열고, 없으면 백엔드 /briefing?project_id=...에서 생성해 워크스페이스에 저장합니다. 프로젝트 정의, 문서 요약, 진입점, 함수 목록, 기능 목록 확인
Sidebar 의존성 그래프 초기화 및 열기 프로젝트 파일의 import 관계를 분석하고 Node/Edge 진행률을 표시합니다. 분석 완료 후 별도 웹뷰에서 그래프를 엽니다. .vscode/dependency-graph.json, Git HEAD 기반 증분 갱신
Sidebar Guide 및 채팅 이력 Vision Guide 패널을 열고 닫으며, VS Code 전역 저장소의 history.db 위치를 외부 파일 탐색기에서 엽니다. vision.showGuideBook은 Guidebook 자동 표시 설정
Sidebar / Chat 프로젝트 인덱싱 프로젝트 목록에서 로컬 프로젝트의 서버 DB 인덱싱 필요 여부를 표시합니다. 실제 인덱싱은 현재 @vision /indexing Chat 명령을 기준으로 안내합니다. Sidebar의 인덱싱 버튼은 현재 메시지 명령 불일치로 실행되지 않음
Explorer 파일 의존성 탐색기 현재 활성 파일의 Imported Files와 Referenced By Current File을 트리로 표시하고 파일 저장 또는 활성 파일 변경 시 갱신합니다. < V > File Dependency
Quick Ask 코드 우클릭 빠른 질문 파일 또는 선택 코드를 @vision 질문으로 VS Code Chat에 주입합니다. vision.explainFile
Vision Chat RAG 질의 및 SSE 응답 @vision이 프로젝트와 코드를 질의하며, 설정에 따라 RAG 또는 No-RAG로 처리하고 SSE 이벤트를 스트리밍합니다. /no-rag, /ragonly, /indexing
Guidebook 기능 안내 및 자동 표시 설정 확장 기능 탭을 제공하며 하단 체크박스로 다음 활성화부터 Guidebook을 자동 표시하지 않도록 설정합니다. vision.showGuideBook
