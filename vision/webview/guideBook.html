A. 프로젝트 인덱싱

프로젝트 인덱싱 관련 기능 명세

기능명 상세 설명 의존성 및 비고 정의 상태
자동 프로젝트 브리핑 인덱싱 완료 후 프로젝트 목적, 주요 디렉터리, 핵심 모듈, 실행 흐름을 요약한 Markdown 브리핑 1편을 생성하고 표시한다. 프로젝트 요약 생성·문서 생성·요약 표시를 하나로 통합. /ingest 계약에 종속. 확정
인덱스 갱신 프로젝트 코드나 문서가 변경된 뒤 사용자가 재인덱싱을 실행할 수 있게 한다. v1에서는 증분 갱신 대신 전체 재실행으로 단순화한다. 실시간 자동 갱신과 파일별 증분 인덱싱은 초기 범위에서 제외. 확정
미인덱싱 감지 프로젝트 폴더가 열리면 해당 프로젝트의 인덱스 존재 여부를 확인하고, 인덱스가 없으면 온보딩 뷰와 인덱싱 실행 안내를 표시한다. project_id 또는 workspace 기준 인덱스 존재 여부를 확인. 확정
인덱싱 진행률 표시 인덱싱 작업의 상태와 처리 파일 수를 주기적으로 조회하여 분석 중, 완료, 실패 상태를 표시한다. processed, total, state 필드 사용. /ingest 계약 동결에 종속. 확정
인덱싱 실행 명령 팔레트 또는 온보딩 뷰에서 프로젝트 인덱싱을 실행한다. 서버는 POST /ingest 요청을 비동기 작업으로 접수하고 job_id를 반환한다. 레포 전체 대상. 코드 Python 우선, 문서 Markdown 우선 처리. 확정
가이드 인덱스 작성 readme.md(임시)에 선임의 개발 방향, 그리고 수정하면 안되는 코드 등의 가이드를 담아놓는 내용을 작성한다. 코드작성 관련 질문 전반에 적용 확정
B. 질의응답

질의응답 관련 기능 명세

기능명 상세 설명 의존성 및 비고 정의 상태
오류 상태 표시 서버 미연결, 인덱스 없음, 모델 사용 불가, 요청 실패를 구분하여 표시하고 사용자가 취할 조치를 안내한다. 오류별 code와 message를 사용하며 단순 실패 문구 하나로 통합하지 않음. 확정
멀티턴 대화 직전 1~2턴을 다음 요청에 포함하여 후속 질문의 문맥을 유지한다. 세션 히스토리 안정화 이후 검토. 핵심 데모 범위 아님. 확정
세션 히스토리 표시 현재 VS Code 세션에서 주고받은 질문과 답변을 목록을 Extension 내부에 저장한다. 서버 측 영구 대화 저장은 범위 제외. X
근거 없음 안내 검색 결과 유사도가 기준에 미달하면 관련 근거를 찾지 못했다는 안내를 표시하고 근거없는 답변 생성을 제한한다. 유사도 임계값과 판정 방식은 RAG 품질 검증 후 기술 명세에서 조정. 보류
단계 표시 질문 처리 중 검색 중, 근거 확인, 답변 생성 중 등의 단계를 표시해 응답 대기 상태를 안내한다. 실시간 서버 이벤트가 없으면 v1에서는 클라이언트 상태 전환 문구로 구현 가능. 확정
선택 코드 첨부 에디터에서 선택한 코드 또는 커서 위치의 코드를 질문 컨텍스트에 첨부하고, 파일 경로와 라인 범위를 입력 영역에 배지로 표시한다. 첨부 상한 200줄. 커서+단축키 트리거 포함. JSON 형식 정의 필요 확정
답변 렌더링 서버가 반환한 답변을 VS Code 채팅 영역에 Markdown으로 표시하고 코드 블록을 읽기 쉬운 형태로 렌더링한다. 코드 블록 syntax highlighting은 프론트 구현에서 조정 가능. 확정
근거 기반 답변 생성 서버가 질문을 임베딩하여 프로젝트 벡터 인덱스에서 top-k 근거를 검색하고, 근거와 질문을 LLM에 주입해 답변을 생성한다. 기업 프로젝트 지식은 fine-tuning이 아니라 RAG 검색으로 공급. 확정
질문 입력·전송 사용자가 VS Code 채팅 사이드바에서 자연어 질문을 입력하면 선택 코드가 있을 경우 code_context와 함께 POST /generate로 전송한다. 프로젝트 구조, 함수 역할, 기능 흐름, 규약, 오류 관련 질문을 지원. 확정
