Extension Overview (확장 프로그램 화면 구성)

화면 구성도 기반의 확장 프로그램 초기 대시보드 영역입니다.

🟢 서버 상태 및 연결 정보

Extension과 백엔드 서버의 연결 상태 및 응답 속도, 서버 URL, sLLM 연결 상태와 모델명 정보를 확인하며, sLLM 답변 스트리밍ON OFF를 선택할 수 있습니다.

📂 현재 프로젝트 정보

선택된 프로젝트의 이름과 경로 정보, 그리고 Git 연동 정보를 직관적으로 표시하며, 프로젝트 구조 분석의 최신 상태를 관리하고 의존성 그래프와 프로젝트 브리핑을 통해 코드 구조를 입체적으로 파악할 수 있습니다.

🔄 프로젝트 목록

사내 서버와 연동되어 관리되고 있는 프로젝트 폴더 목록을 표시하며, 새로고침으로 목록을 갱신합니다.

📖 Vision Guide

Chat history.db 열기 및 가이드북 자동 표시 여부를 설정할 수 있습니다.

FILE DEPENDENCY (파일 의존성 탐색기)

현재 활성화된 파일의 의존성 관계(Imported Files 및 Referenced By Current File)를 트리 형태로 직관적으로 파악할 수 있는 화면입니다.

📂 FILE DEPENDENCY 트리 구조 및 기능 설명

현재 파일에서 가져온 외부 모듈/파일 목록과, 반대로 현재 파일을 참조하고 있는 연관 파일들을 한눈에 파악하여 효율적인 연관 코드 수정을 지원합니다.

  • Imported Files: 현재 파일에서 import하여 사용 중인 모듈 및 소스 파일 목록을 표시합니다.
  • Referenced By Current File: 현재 파일 또는 모듈을 참조하고 있는 프로젝트 내 타 파일 목록을 표시합니다.

코드 빠른 질문 (Code Quick Ask)

코드 작성 및 유지보수 중 빠르게 질문을 던질 수 있는 기능 구성입니다.

🖱️ 자동 코드 인젝션

코드를 드래그하고 우클릭 메뉴에서 "vision: 이 코드 설명해줘"를 선택하면, 선택된 파일명과 코드 블록(@vision)이 VS Code 챗 창에 자동으로 첨부됩니다.

⚡ 실시간 AI 설명

전송 시 백엔드와 연동되어 해당 코드에 대한 상세한 AI 설명을 즉시 받아볼 수 있습니다.

의존성 그래프 시각화 (Dependency Graph)

프로젝트 내부 파일 간의 호출 및 참조 관계를 시각적으로 분석하는 기능 구성입니다.

📈 인터랙티브 그래프 맵

프로젝트 전체 소스 코드의 결합도와 모듈 간 의존 구조를 노드와 링크 형태로 시각화하여 복잡한 아키텍처를 쉽게 파악할 수 있도록 돕습니다.

  • 구조 파악: 특정 모듈 변경 시 영향받는 연관 파일을 직관적으로 추적
  • 노드 상호작용: 개별 노드 선택 시 상세 파일 경로 및 연결 정보 조회 가능

🔍 심층 의존성 분석 요약

그래프 데이터를 기반으로 순환 참조나 결합도가 높은 핵심 컴포넌트를 탐지하여 코드 리팩토링 가이드를 제공합니다.

  • 핵심 모듈 식별: 프로젝트 내에서 가장 많이 참조되는 중심 파일 파악
  • 유지보수 최적화: 불필요한 의존성 제거 및 구조 개선 포인트 제안

프로젝트 브리핑 (Preview brief.md)

현재 선택된 프로젝트의 전체 구조, 문서 요약, 주요 진입점(Entry Points) 및 함수 목록을 마크다운 미리보기 형태로 제공하여 코드베이스 이해를 돕습니다.

📄 프로젝트 개요 및 요약 (Document Summary)

프로젝트가 어떤 목적을 가진 시스템인지(예: HTTPie CLI 툴 등) 대요를 설명하고, 주요 핵심 문서(README, 패키지 가이드 등)들의 구조를 깔끔하게 요약하여 보여줍니다.

  • 프로젝트 정의: 프로젝트의 핵심 역할 및 목표 직관적 제공
  • 문서 인덱스: 주요 문서 경로 및 구조 빠르게 파악

🚀 진입점(Entry Points) 및 함수 분석

프로젝트가 시작되는 핵심 실행 파일들과 판정 근거, 그리고 각 진입점별 주요 함수 목록을 체계적으로 정리하여 코드 분석의 출발점을 제시합니다.

  • 진입점 관리: __main__.py, cli.py, run.py 등 핵심 실행 파일 위치 및 판정 근거 명시
  • 함수 리스트: 주요 진입점 내부의 핵심 함수(def main() 등) 구조 요약

Vision Chat 상세 가이드

VSCode Chat API 기반의 Vision Assistant 참가자 동작 및 활용 안내입니다.

🤖 Vision Assistant 개요

VSCode 내장 Chat UI에서 @vision 참가자를 선택하여 프로젝트 기반 질문을 진행합니다.

  • 등록 ID: vision.chat
  • 참가자 이름: @vision (Vision Assistant)

⚡ 핵심 채팅 처리 프로세스

사용자 질문 입력 시 컨텍스트와 대화 이력을 결합하여 SSE 스트리밍 응답을 출력합니다.

  • 프롬프트 구성: 질문 정리 및 대화 이력(context.history) 병합
  • 컨텍스트 포함: 현재 활성 편집기 파일 전체 텍스트 자동 첨부
  • 응답 전송: 백엔드 SSE 기반의 점진적 스트리밍 응답 제공 (chatHandler_SSE.ts)

💡 주요 명령어 및 활용 팁

채팅 창과 편집기 명령어를 통해 손쉽게 AI 컨텍스트를 활용할 수 있습니다.

  • 코드 설명: 우클릭 메뉴 또는 명령 팔레트 vision: 이 코드 설명해줘 (ID: vision.explainFile)
  • 가이드북 조율: vision.showGuide / vision.toggleGuide
  • 컨텍스트 팁: 활성 편집기를 유지한 채 질문하면 해당 코드 컨텍스트가 함께 전송됩니다.
