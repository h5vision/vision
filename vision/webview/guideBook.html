Extension Overview (확장 프로그램 화면 구성)

화면 구성도 기반의 확장 프로그램 초기 대시보드 영역입니다.

🟢 서버 상태 및 연결 정보

Extension과 백엔드 서버의 연결 상태 및 응답 속도, 서버 URL, sLLM 연결 상태와 모델명 정보를 확인합니다.

📂 현재 프로젝트 정보

선택된 프로젝트의 이름과 경로 정보, 그리고 Git 연동 정보를 직관적으로 표시합니다.

🔄 프로젝트 목록

사내 서버와 연동되어 관리되고 있는 프로젝트 폴더 목록을 표시하며, 새로고침으로 목록을 갱신합니다.

Vision Assistant & 코드 유지/보수 화면

AI 채팅과 VS Code 탐색기가 유기적으로 연동되는 화면 구성입니다.

🤖 초기 자동 브리핑

프로젝트가 열리면 프로젝트 이름, 구성 정보, 현재 열려 있는 파일의 역할을 AI가 먼저 분석하여 설명해 줍니다.

🔴 현재 열린 파일 강조

VS Code 탐색기에서 현재 화면에 열려 있는 파일과 연관성이 높은 파일 이름들을 빨간색으로 시각적 구분 표시합니다.

🔵 sLLM 출처 파일 표시

AI가 답변의 근거로 제시한 파일 이름들을 파란색으로 표시하여 원본 위치를 직관적으로 추적할 수 있습니다.

코드 빠른 질문 (Code Quick Ask)

코드 작성 및 유지보수 중 빠르게 질문을 던질 수 있는 기능 구성입니다.

🖱️ 자동 코드 인젝션

코드를 드래그하고 우클릭 메뉴에서 "vision: 이 코드 설명해줘"를 선택하면, 선택된 파일명과 코드 블록(@vision)이 VS Code 챗 창에 자동으로 첨부됩니다.

⚡ 실시간 AI 설명

전송 시 백엔드와 연동되어 해당 코드에 대한 상세한 AI 설명을 즉시 받아볼 수 있습니다.
