Extension Overview (확장 프로그램 화면 구성)

화면 구성도 기반의 확장 프로그램 초기 대시보드 영역입니다.

🟢 서버 상태 및 연결 정보

Extension과 백엔드 서버의 연결 상태 및 응답 속도, 서버 URL, sLLM 연결 상태와 모델명 정보를 확인합니다.

📂 현재 프로젝트 정보

선택된 프로젝트의 이름과 경로 정보, 그리고 Git 연동 정보를 직관적으로 표시합니다.

🔄 프로젝트 목록

사내 서버와 연동되어 관리되고 있는 프로젝트 폴더 목록을 표시하며, 새로고침으로 목록을 갱신합니다.

Vision Assistant & 코드 유지/보수 화면

AI 채팅과 VS Code 탐색기가 유기적으로 연동되는 화면 구성입니다.

🤖 초기 자동 브리핑

프로젝트가 열리면 프로젝트 이름, 구성 정보, 현재 열려 있는 파일의 역할을 AI가 먼저 분석하여 설명해 줍니다.

🔴 현재 열린 파일 강조

VS Code 탐색기에서 현재 화면에 열려 있는 파일과 연관성이 높은 파일 이름들을 빨간색으로 시각적 구분 표시합니다.

🔵 sLLM 출처 파일 표시

AI가 답변의 근거로 제시한 파일 이름들을 파란색으로 표시하여 원본 위치를 직관적으로 추적할 수 있습니다.

코드 빠른 질문 (Code Quick Ask)

코드 작성 및 유지보수 중 빠르게 질문을 던질 수 있는 기능 구성입니다.

🖱️ 자동 코드 인젝션

코드를 드래그하고 우클릭 메뉴에서 "vision: 이 코드 설명해줘"를 선택하면, 선택된 파일명과 코드 블록(@vision)이 VS Code 챗 창에 자동으로 첨부됩니다.

⚡ 실시간 AI 설명

전송 시 백엔드와 연동되어 해당 코드에 대한 상세한 AI 설명을 즉시 받아볼 수 있습니다.

🚀 FastAPI 신규 개발자 온보딩 & 프로젝트 브리핑

Github에 등록된 FastAPI 프로젝트의 구조, 핵심 로직 및 신규 개발자가 반드시 알아야 할 상세 가이드입니다.

📢 FastAPI 프로젝트 전체 브리핑 실행

클릭 즉시 VS Code 챗 창을 통해 Github FastAPI 소스 코드 전체 구조와 핵심 로직에 대한 상세 자동 브리핑을 시작합니다.

🏛️ 프로젝트 아키텍처 및 디렉토리 구조

FastAPI 기반 백엔드의 계층형 구조(Router, Service, Repository, Schema)를 이해하고 각 폴더의 책임을 파악합니다.

  • routers/: API 엔드포인트 및 요청/응답 처리
  • services/: 비즈니스 로직 수행
  • models/ schemas/: DB 모델 및 Pydantic 데이터 검증

💉 의존성 주입 (Dependency Injection)

FastAPI의 핵심 기능인 Depends를 활용한 DB 세션 관리, 인증(Authentication) 및 공통 모듈 주입 방식을 확인합니다.

🔄 신규 기능 개발 및 수정 워크플로우

깃허브 소스 코드를 클론한 후 브랜치 전략에 맞춰 API를 추가하고, Pydantic 모델을 통한 데이터 유효성 검증을 구현하는 절차를 익힙니다.

📋 FastAPI 핵심 구성 요소 명세

구분 모듈 / 파일명 역할 및 설명 수정 시 주의사항
Entrypoint main.py FastAPI 앱 인스턴스 생성, CORS 설정 및 라우터 등록 미들웨어 추가 시 순서 유의
Validation schemas.py Pydantic 기반의 Request/Response 데이터 구조 정의 API 스펙 변경 시 프론트엔드와 사전 공유
Database database.py SQLAlchemy 세션 설정 및 Base 모델 정의 비동기(Async) 세션 핸들링 주의

🛠️ 실무 개발 가이드 & 트러블슈팅

신규 개발자가 코드를 수정하고 API를 개발할 때 자주 겪는 예외 처리, 비동기 세션 관리, 테스트 요령을 안내합니다.

⚠️ 에러 핸들링 및 예외 처리

HTTPException을 활용한 커스텀 에러 응답 반환 및 전역 예외 처리기를 통해 표준화된 에러 JSON 포맷을 유지합니다.

⚡ 비동기 프로그래밍 (Async/Await)

I/O 바운드 작업(DB 쿼리, 외부 API 호출) 시 async def와 일반 def의 차이점 및 SQLAlchemy 비동기 세션 관리 주의사항을 숙지합니다.

🧪 API 문서화 및 단위 테스트

자동 생성되는 Swagger UI(/docs)의 Pydantic Field 예시 작성 팁과 Pytest를 활용한 엔드포인트 테스트 방법을 익힙니다.

📋 실무 필수 체크리스트

구분 체크 항목 설명
Security 환경 변수 관리 .env 파일을 통한 비밀키 및 DB 접속 정보 분리 관리
Validation Pydantic 타입 힌팅 모든 Request Body 및 Query Parameter에 명확한 타입 정의
Performance N+1 쿼리 방지 SQLAlchemy selectinload 또는 joinedload 활용
