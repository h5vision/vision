# Snapshot Backend Agent 문서

이 디렉터리는 `backend_P` Snapshot 기능을 새로운 Chat/Agent가 이어서 구현하기 위한 기준 문서입니다.

| 문서 | 목적 |
|---|---|
| `01_REFERENCE_REPOSITORIES.md` | 참조 저장소, 브랜치, 기준 SHA와 중요 파일 |
| `02_EXTERNAL_CONTRACTS.md` | Frontend 수신 계약과 Model 전달 계약 |
| `03_TARGET_STRUCTURE.md` | 권장 폴더 구조와 파일별 책임 |
| `04_REQUIRED_FEATURES.md` | 구현해야 할 기능과 상태/오류 처리 |
| `05_IMPLEMENTATION_PLAN.md` | 구현 순서, 테스트 및 완료 조건 |
| `06_READINESS_AND_VERIFICATION.md` | 구현 전 필수 입력값, 중단 조건과 단계별 검증 증거 |

루트 `AGENTS.md`의 규칙이 이 문서들의 공통 상위 지침입니다.
